Spazio e pulizia completa




Con una run attiva, la pulizia salva e verifica un checkpoint, avvia da esso una nuova run senza storico e riprende. Se nessuna run è attiva, svuota direttamente lo storico SQLite. I checkpoint esterni restano disponibili. Un errore nel salvataggio o nel ripristino conserva lo storico.


Come leggere lo spazio

La barra misura la quota occupata del filesystem. Il dettaglio del database include SQLite, WAL e SHM. Le pagine riutilizzabili restano nel file dopo la rimozione di una singola run; la pulizia completa sostituisce il file e recupera lo spazio sul filesystem.


Il limite database_limit_gb è 10 GB decimali per impostazione predefinita. Al raggiungimento della soglia viene eseguita automaticamente la stessa rotazione. In WSL il filesystem è contenuto in un disco virtuale; la disponibilità reale sul disco Windows non viene misurata qui.
